# Skills — instaladas y útiles aquí

Registro completo en la salida de `skill` / `available_skills`. Las más relevantes para este repo:

## En el proyecto (`.opencode/`, `.agents/`)

| Skill | Uso |
|---|---|
| `security-audit` | Auditoría de seguridad antes de deployar (auth, secrets, dependencias, OWASP) |
| `storyteller` | Copy humano para case studies, hero y proyectos |
| `balsa-ui` / `balsa-template-design` | Componentes/plantillas Balsa (Vue) — solo si se usa Balsa |
| `json-canvas` / `obsidian-bases` | Archivos `.canvas` / `.base` de Obsidian |

## Globales (`~/.config/opencode/`, `~/.agents/`)

| Skill | Uso |
|---|---|
| `frontend-design` | Interfaces con dirección visual fuerte |
| `ux-audit` / `ux-heuristics-review` | Auditorías UX estructuradas (CRAP, WCAG, heurísticas) |
| `accessibility` | Revisión WCAG 2.1 de diseños/capturas |
| `design-system-portfolio` | Anti-patrones "AI slop" para portfolios |
| `impeccable-design-polish` | Pulido post-implementación (animación, live prep) |
| `design-news` | Novedades de design/product/AI |
| `defuddle` | Extraer markdown limpio de URLs (usar en vez de WebFetch) |
| `crm-sync` / `notion-crm` / `lead-capture` / `proposal-generator` / `audit-to-proposal` | Flujo comercial (leads, propuestas) |
| `mermaid-diagram` | Diagramas de arquitectura/workflows |
| `customize-opencode` | Solo al tocar config de OpenCode (`opencode.json`, `.opencode/`) |

## Regla

Cargar con la herramienta `skill` cuando la tarea coincida con la descripción; no reimplementar lo que una skill ya documenta.
