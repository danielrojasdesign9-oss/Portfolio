## ENGLISH

### Title
TIR — Tax Information Reporting

### Category
Tax Information Reporting / Compliance

### Year
2025

### Client
Sovos — Internal Products

### Location
Remote — LATAM

### My Role
Product Designer — Compliance Dashboards for Tax Officers across 15+ LATAM countries

### The Problem
A single error in a tax report can cost $50,000+ in fines. Across LATAM, regulations change constantly — sometimes monthly. Companies were drowning in manual processes:

- **15+ countries**, each with different formats, deadlines, and requirements
- **Manual data entry** leading to costly errors and penalties
- **No visibility** into compliance status across jurisdictions
- **Excel hell** — tax officers spending more time formatting than analyzing

### Product Vision
**Automated, real-time tax compliance that scales across LATAM.**

A unified platform that handles tax reporting for multiple countries, with automated data extraction, validation, and submission — so tax officers can focus on strategy, not spreadsheets.

### What I Did
1. **Dashboard Design**: Created compliance dashboards showing real-time status across 15+ countries
2. **Data Visualization**: Designed visual indicators for deadline urgency and error severity
3. **Automated Workflows**: Built flows that reduced manual data entry by 60%
4. **Multi-country Adaptation**: UI that adapts to different tax regulations per country

### The Process
The main challenge? **Every country is different.** Argentina's requirements look nothing like Chile's, and Brazil is its own universe.

**Attempt 1**: I tried a unified design for all countries. Failed spectacularly. Each country has unique fields, validation rules, and deadline structures.

**Attempt 2**: Built a modular system where each country template is a configuration, not a custom build. This worked.

**Key insight**: Compliance officers don't need pretty dashboards — they need **clear signals** about what's urgent, what's at risk, and what's done.

### The Result
- **60% reduction** in manual data entry
- **Real-time compliance dashboards** across 15+ countries
- **40% fewer errors** through automated validation
- **Scalable design system** supporting rapid country expansion

### What I Learned
- **Compliance is complex**: Each country has unique requirements that can't be oversimplified
- **Automation needs trust**: Users need to verify automated data before submission — never auto-submit
- **Localization matters**: Date formats, currencies, and regulations vary significantly
- **"Boring" design wins**: In compliance, clarity beats creativity every time

### Tech Stack
- React/Next.js
- TypeScript
- Tailwind CSS
- Carbon Design System
- D3.js for data visualization

## 日本語

### タイトル
TIR — 税務情報報告

### カテゴリー
税務情報報告 / コンプライアンス

### 年
2025

### クライアント
Sovos — 社内製品

### 場所
リモート — LATAM

### 私の役割
プロダクトデザイナー — 15以上のLATAM国の税務担当者向けコンプライアンスダッシュボード

### 課題
税務報告の1つのエラーで50,000ドル以上の罰金が発生する可能性があります。LATAMでは規制が絶えず変更されています — 場合によっては月次で。企業は手動プロセスに溺れていました：

- **15以上の国**、それぞれ異なるフォーマット、締め切り、要件
- **手動データ入力**による高コストなエラーと罰金
- **コンプライアンス状況の可視性欠如** — 管轄間
- **地獄のExcel** — 税務担当者が分析よりもフォーマットに時間を費やす

### プロダクトビジョン
**LATAM全体でスケールする自動リアルタイムコンプライアンス。**

自動データ抽出、検証、送信を処理する複数国の税務報告を統一プラットフォーム — 税務担当者がスプレッドシートではなく戦略に集中できるように。

### 私がやったこと
1. **ダッシュボード設計**: 15以上の国でリアルタイムの状況を表示するコンプライアンスダッシュボードを作成
2. **データ可視化**: 締め切りの緊急性とエラーの重大度を示す視覚的指標を設計
3. **自動化ワークフロー**: 手動データ入力を60%削減するフローを構築
4. **多国適応**: 国別の税務規制に適応するUI

### プロセス
最大の課題は？**各國が異なる。**アルゼンチンの要件はチリのものとは全く異なり、ブラジルは独自の宇宙です。

**試行1**: すべての国で統一されたデザインを試みました。劇的に失敗しました。各國には固有のフィールド、検証ルール、締め切り構造があります。

**試行2**: 各国のテンプレートをカスタムビルドではなく構成として扱うモジュラーシステムを構築しました。これは機能しました。

**重要な洞察**: 税務担当者にはきれいなダッシュボードは不要 — **明確なシグナル**が必要です。何が緊急で、何がリスクがあり、何が完了しているかを。

### 結果
- 手動データ入力の**60%削減**
- 15以上の国での**リアルタイムコンプライアンスダッシュボード**
- 自動検証による**40%エラー削減**
- 迅速な国別展開をサポートする**スケーラブルなデザインシステム**

### 学んだこと
- **コンプライアンスは複雑**: 各国には単純化できない固有の要件がある
- **自動化には信頼が必要**: ユーザーは送信前に自動化されたデータを確認する必要がある — 送信は自動化しない
- **ローカリズーションが重要**: 日付形式、通貨、規制は大きく異なる
- **「退屈な」デザインが勝つ**: コンプライアンスでは、明確さが常に創造性に勝る

### 技術スタック
- React/Next.js
- TypeScript
- Tailwind CSS
- Carbon Design System
- D3.js（データ可視化用）
